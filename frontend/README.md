# StudyDocs Pipeline — Frontend

SPA en React + TypeScript + Vite + Tailwind + Framer Motion: portada, demo interactiva y decisiones
técnicas del proyecto [StudyDocs Pipeline](../README.md).

```bash
npm install
npm run dev      # servidor de desarrollo con hot-reload, proxy a la API en :3000
npm run build    # build de producción en dist/, servido por el backend Fastify
npm run lint
```
